# Learning steps

These scripts preserve the smaller exercises used while building the project. Run them from the project directory, for example `uv run python examples/lessons/claim_check.py`. The packaged `claims-agent` command in the main README is the supported full workflow.

- `claim_check_early.py` and `claim_check.py`: required fields and conditional graph paths.
- `tool_call.py`: one model-requested policy lookup.
- `persistent_chat.py`: SQLite-backed tool conversation.
- `review_pause.py` and `review_resume.py`: a minimal standalone interrupt/resume exercise.
